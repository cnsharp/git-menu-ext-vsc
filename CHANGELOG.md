# Changelog

## 1.1.0 (2026-06-30)

- Add editor context menu with Git submenu (Stage/Unstage/Discard/Open Changes/Compare with Branch/Show File History)
- Show File History — WebView commit list with diff viewer for each revision
- Menu items are context-aware: Stage/Unstage/Discard only appear when applicable

## 1.0.0 (2026-06-29)

- Initial release
- Copy Branch Name — copy current branch name to clipboard
- Delete Branches — batch delete branches matching a keyword, with optional remote deletion
- Delete Outdated Branches — delete branches whose remote tracking is gone
- Squash Commits — squash multiple recent commits into one with deduplicated messages
- Export Changed Files — export files changed between two commits as zip or directory
